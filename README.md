# ✨ StudioBooth Pro - Aesthetic HD PhotoBooth

Aesthetic Web PhotoBooth dengan **kualitas kamera HD, efek bokeh optik alami (DSLR Depth of Field), filter studio natural ala Korea, dan kartu 3D interaktif**.

Dibuat murni dengan **HTML5, CSS3, dan Vanilla JavaScript** tanpa library/framework berat, 100% aman untuk privasi, dan **langsung siap dideploy ke GitHub Pages (`github.io`)**!

---

## 🌟 Fitur Unggulan:

1. **Peningkatan Kualitas Kamera HD**:
   - Meminta resolusi sensor tertinggi kamera webcam/ponsel (hingga 1080p Full HD / 4K ideal).
   - Fitur **Auto Sharpness & Clarity HD**: Meningkatkan kejernihan dan kontras kamera agar tidak terlihat kusam atau washed out.
   - Pilihan kamera depan & belakang (*Flip Cam*) + mode cermin (*Mirror*).

2. **Bokeh Alami (Optical Depth of Field)**:
   - Efek bokeh realistis layaknya lensa potret DSLR (tanpa partikel norak).
   - Fokus tajam di bagian tengah wajah pengguna, dengan latar belakang dan tepi foto yang memudar lembut secara alami (*smooth radial fall-off*).
   - 3 Pilihan Bukaan Lensa:
     - **Halus (f/2.8)**: Blur tipis natural.
     - **Lembut (f/2.0)**: Blur standar potret studio.
     - **Mendalam (f/1.4)**: Blur creamy mendalam.
   - Efek bokeh alami ini otomatis digabungkan (*blended*) dengan halus ke dalam hasil foto akhir saat diunduh!

3. **8 Filter Studio Natural & Elegan**:
   - **Studio HD**: Jernih, bersih, dan tajam.
   - **K-Clean ✨**: Kulit cerah lembut khas studio foto Korea (Life Four Cuts / Haru Film).
   - **Kodak 35mm 🎞️**: Tone film hangat klasik.
   - **Golden Hour 🌅**: Kehangatan cahaya matahari sore.
   - **Classic B&W 🖤**: Hitam putih monochrome tajam.
   - **Fuji Tone 🍃**: Warna hijau sejuk khas Fuji Velvia.
   - **Soft Pastel 🌸**: Nuansa manis pastel lembut.
   - **Cool Moody 🌌**: Nuansa modern sinematik.

4. **Sensasi Kartu 3D Realistis**:
   - Kartu photobooth di sebelah kanan memiliki efek 3D halus saat kursor digerakkan atau layar disentuh.
   - Dilengkapi kilau pencahayaan halus (*card glare*) yang elegan.

5. **Format Tata Letak (Layouts)**:
   - **4-Cuts Strip**: Format vertikal 4 foto khas photobooth Korea.
   - **2x2 Grid**: 4 foto kotak estetik modern.
   - **3-Cuts Strip**: Format vertikal 3 foto.
   - **Single Polaroid**: Foto polaroid tunggal dengan ruang footer lebar.

6. **Privasi 100% Aman (Client-Side)**:
   - Berjalan murni di browser pengguna tanpa database/server.
   - Foto otomatis terhapus seketika tombol **Reset / Foto Ulang** diklik atau halaman di-refresh.

## 🌐 Cara Deploy ke GitHub Pages (github.io):
1. Buat repositori baru di [GitHub](https://github.com/new) (contoh: `photobooth`).
2. Di folder project (`d:\yuhuuuu`), jalankan:
   ```bash
   git init
   git add .
   git commit -m "StudioBooth Pro: HD Camera & Natural Bokeh"
   git branch -M main
   git remote add origin https://github.com/USERNAME_ANDA/photobooth.git
   git push -u origin main
   ```
3. Buka repositori di GitHub -> **Settings** -> **Pages** -> pilih branch **main** -> klik **Save**.
4. Website Anda siap digunakan di:
   ```
   https://USERNAME_ANDA.github.io/photobooth/
   ```
